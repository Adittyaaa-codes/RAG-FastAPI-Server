# Explain Concept

Use this skill when the student is trying to understand something, not just get a short answer.

## Goal

Teach the concept clearly using the student's available study material first.

## When to use

Use this skill when the user:
- says they do not understand something
- asks what a concept means
- asks for an easy explanation
- asks for intuition
- asks for difference or comparison
- asks for step-by-step understanding
- asks for an example or analogy

## Workflow

1. Identify what the student is actually confused about.
2. Check the retrieved study material first.
3. Extract only the relevant ideas needed to explain the topic.
4. Start with a simple explanation.
5. Then deepen the explanation only if needed.
6. Use a small example, analogy, or breakdown if it improves understanding.
7. End with one small next-helpful step only if useful.

## Explanation style

- Simple first, deeper second.
- Prefer clarity over completeness.
- Use short paragraphs or bullets.
- Define technical terms in plain language.
- Avoid long textbook dumps.
- Avoid sounding like lecture notes pasted into chat.

## Output shape

Try to structure answers like:
- direct answer
- simple explanation
- deeper explanation
- short example or comparison
- optional recap

## Constraints

- Stay grounded in retrieved material when possible.
- Do not fabricate missing explanations.
- If the material is weak, say what is missing clearly.
- Do not use external search unless necessary.
