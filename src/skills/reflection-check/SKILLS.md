# Reflection Check

Use this skill as a self-review layer before returning the final answer.

## Goal

Improve answer quality by checking whether the response is actually useful, grounded, and understandable.

## When to use

Use this skill when:
- the question is complex
- the answer depends on multiple retrieved pieces
- the response is long or step-by-step
- the topic is easy to hallucinate
- the question is ambiguous
- the first draft may be too advanced, too vague, or incomplete

## Review checklist

Check the draft answer against these questions:

1. Did the answer actually address the student's question?
2. Is the answer grounded in the available retrieved study material?
3. Is anything unsupported or overly confident?
4. Is the explanation understandable for a learner?
5. Is the answer too shallow, too long, or too advanced?
6. Are important steps missing?
7. Would this answer help the student learn, not just read?

## If issues are found

Revise the answer by:
- removing unsupported claims
- simplifying difficult parts
- tightening structure
- filling important gaps when supported by context
- asking for clarification if the task is too ambiguous
- admitting insufficiency if the material is not enough

## Constraints

- Do not expose this reflection process to the student.
- Do not mention hidden reasoning or internal critique.
- Use this skill to improve quality silently.
- Prefer a smaller correct answer over a larger weak one.
